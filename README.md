# Ordo — agentic AI for revenue ops (concept)
Portfolio concept #01 by Anorix. Inspired by Dayos; original brand, copy, layout and assets.

    npm install
    npm run build
    npm start        # http://localhost:3010

Dev: `npm run dev` (also port 3010). Stack: Next.js 16 App Router, TypeScript, Tailwind 4, GSAP + ScrollTrigger + SplitText, Lenis, three.js / R3F.
