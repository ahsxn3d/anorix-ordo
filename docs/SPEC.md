# 01 — ORDO (AI SaaS concept) — inspired by Dayos (Awwwards SOTD May 29 2025)

## What the reference does well (studied live, Playwright 1440 + 390)
- Swiss/industrial voice: condensed ALL-CAPS bold display (Suisse Intl Cond, -2..-3% tracking), neutral grotesk body, mono micro-labels.
- Hard ink ↔ paper rhythm: dark sections and light "sheets" with large rounded top corners that slide over the previous section.
- One loud accent (yellow pill CTA) used sparingly; floating centered pill nav.
- Product-as-hero: a live agent console (steps REQUEST → UNDERSTAND → EXECUTE → VALIDATE) instead of a stock image.
- Three-beat statements ("AI. GAP. CLOSED."), giant thesis lines, tabbed department list with a ledger table, IMPLEMENT/OPERATE/COMPOUND diagram, use-case carousel with soft 3D renders, integrations grid, black footer.

## Ordo — original concept
"Ordo — agentic AI for revenue operations." Agents that run pipeline hygiene, billing, collections, forecasting and renewals inside the CRM/billing stack.
Original name, copy, glyph, layout, palette and imagery. No reference code, fonts, logos or images used.

## Design system
- Palette: ink #0C0D0F, graphite #17181B, line #2A2C31, paper #ECEAE4, bone #F6F4EF, mute #8A8C91, accent "ion mint" #7CFFC4 (no pure #000/#FFF).
- Type: Archivo variable (wdth 62–125; display at wdth 70 / 800), Inter variable body, JetBrains Mono labels. All OFL, self-hosted via Fontsource.
- Grid: 12 cols, 24px gutter desktop / 4 cols 16px mobile, max 1440, generous 160px section padding desktop.

## Sections
1. Pill nav + mint CTA. 2. Hero: masked line reveal + blur headline, live "agent run" console cycling steps. 3. Paper sheet: SIGNAL. NOISE. SOLVED. + scrub-fill thesis line.
4. SIGNATURE — "The Core": pinned 3-chapter R3F scene; 3–4k instanced tasks go chaos → ordered sphere lattice → orbital agent rings, synced chapter copy + progress.
5. Departments: big condensed tab list + ledger console (auto-advancing, click). 6. SHADOW → TAKE OVER → COMPOUND: horizontal pinned track (desktop) / stacked (mobile) with animated SVG diagrams.
7. Use-case carousel (draggable, self-generated renders, image clip reveal + parallax). 8. Metrics count-up. 9. Quote with word-by-word blur reveal. 10. Giant CTA + footer wordmark.

## Motion
Lenis smooth scroll driving GSAP ScrollTrigger; SplitText line/char masks; blur-to-sharp reveals; sheets with rounded tops overlapping; reduced-motion respected. 3D lazy-mounted near viewport, DPR capped, paused off-screen.
